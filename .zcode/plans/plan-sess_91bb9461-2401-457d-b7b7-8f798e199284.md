# 优化方案：视频伪影 + GLB 破碎/空洞

## 一、根因诊断（基于现有数据，已核实）

### 视频伪影（background_video.mp4，指标见 video_evaluation.json / comparison_report.json）
1. **780–900 沙发连续漏检是最大来源**：该窗口 mask 覆盖率仅 0.06–0.18；参数搜索片段（760–990）copy_mean≈0.45–0.52、copy>0.2 达 205–227/229 帧——沙发几乎没被移除，且 ProPainter 光流会把未遮罩邻帧里的沙发整块拷回到已遮罩帧。全片 copy_through_mean 仍有 0.136，闪烁比 0.949。
2. **时序中值平滑无运动对齐**：相机在移动（101 关键帧、7 个子图），对 mask 内做 3 帧像素中值（累计改动 3.69 亿像素≈每帧 40% 画面）会把邻帧错位纹理中值进来 → 糊化/重影类新伪影。
3. **首现延迟 ~9 帧**仍有残留；两遍反哺只处理"mask 内"拷贝，对漏检窗口无效。
4. **可复现性缺口**：两遍反哺、时序中值、再封装都是临时工具步骤，未进 cli 主流水线；重跑会丢。
5. ProPainter 用 n=40 是 OOM 后的次优（n=80 全片 OOM@138GB：clip 上 copy 0.449 vs 0.497）。

### GLB 破碎/空洞（geometry_report.json）
1. **前景身后无深度观测**：TSDF 融合时 `(confidence<cutoff)|foreground` 全部清零（vbr/geometry.py:640），沙发/柜子背后永远是洞 → 空洞之根。
2. **墙体无点支撑 → AABB 假墙**：背景点仅 17,831 个；RANSAC 5 个平面全部是水平面（floor/ceiling/台阶），墙无支撑 → `wall_source=robust_footprint_fallback`，用点云 AABB 画 4 面平面假墙+9 个刻洞。假墙与 TSDF 真墙面交叉/重叠 → 破碎、穿洞、z-fighting。
3. **无网格后处理**：没有连通域清理（浮渣）、补洞、重复面去重；子图尺度跳跃（1.0 vs 0.29–0.62，reconstruction stage）需诊断是否造成表面叠影。
4. 假墙刻的 9 个开口按 see-through 证据打在错误平面上，形成肉眼可见的穿墙洞。

## 二、优化策略与实施步骤

### 视频侧（先做：GLB 重估深度依赖最终视频，天然有顺序依赖）

**V1 持续漏检窗口局部重探测（治本，保留精准原则）**
- `vbr/video.py` 新增 `detect_persistent_misses(masks_dir, ...)`：用 mask_statistics 的逐帧覆盖率找"≥30 帧且覆盖率≤0.15"的窗口（预期命中 780–900）。
- `vbr/cli.py` 新增 `_refine_miss_windows(...)`（复用 `_refine_onset_seeds` 的机制）：对窗口做局部稠密 SAM3.1 重探测，先经 probe 审计验证新增 prompt（sofa、couch、sofa bed、armchair、cushions、throw blanket 等，排除与 preserve 冲突者）→ 新 seeds 并入 `masks_keyframes_sam31_onset` → 钉住重传播 → 重建 `masks_inpaint` → 重跑 ProPainter。**只有漏检窗口 mask 局部扩大，其余帧不变**。
- 回退：若文本 prompt 对该沙发依然失效，提供窗口内人工 box seed 配置项（坐标写入 config，可审查），用 SAM3.1 box prompt 兜底。
- 配置：`segmentation.miss_refinement {enabled, max_windows, min_window_frames, min_coverage, extra_prompts}`（default.yaml 与 vggt_slam.yaml）。

**V2 光流对齐时序平滑（替换无对齐中值）**
- 新增 `vbr/temporal_smooth.py`：用 ProPainter 自带 RAFT 权重（vbr-seg 环境）估计 t-1/t+1→t 的反向光流，warp 后再对 mask 内做 3 帧中值；相机运动下的错位重影消除。
- 接入 `vbr/cli.py` video stage（ProPainter 之后、最终 h264+aac 封装之前），配置 `video_completion.temporal_smooth {enabled, kernel}`；`tools/post_temporal_smooth.py` 保留为兼容工具。单元测试：合成平移场景验证光流对齐优于朴素中值、帧数守恒。

**V3 ProPainter 分块 n=80（可选、按收益评估）**
- `vbr/models/inpainting.py` 增加分块模式：1799 帧按 ~240 帧/块、重叠 60 帧切分，每块 n=80/ref_stride=10 独立跑（与搜索片段同规模、不 OOM），重叠区取第二块结果拼接。
- 先在 760–990 片段上验证 copy 下降（预期 0.497→0.449），满意再全片；配置 `video_completion.chunks {enabled, size, overlap}`。

**V4 度量与验收**
- 视频评估增加"分窗口 copy 报告"与 glitch 帧计数（mask 内时序梯度超阈值帧占比），写入 video_evaluation.json 新条目。

### GLB 侧

**G1 背景视频重估深度（治本）**
- 从最终背景视频抽取 `frames_background/`（jpg q95，1799 帧），并生成全 0 的 `masks_empty/`。
- `SLAMAdapter.run(frames_background, slam_dir_background, masks_empty)` 重跑 vggt_slam 后端（GPU7、vbr-slam，不动原 slam/ 结果）：前景区现在有修复纹理 → 深度可估 → TSDF 融合后沙发/柜子后面对应变连续墙面；点云量应显著超过 17,831。
- 对子图尺度（1.0 vs 0.29–0.62）做诊断并在融合前校验：若发现尺度不一致导致叠影，则逐子图归一化后再融合（先诊断后修）。
- 用新 npz/ply 重跑 geometry stage（`build_mesh`），结构体仍保留 door/stairs opening_hints。

**G2 结构体墙改造（消灭假墙交叉）**
- 深度重估后墙体点支撑应恢复 → 3D RANSAC / `fit_wall_lines` 应检出真墙（`wall_source → ransac/plan_ransac`），footprint 假墙仅作最后兜底。
- 若仍兜底：把假墙偏移改为"各墙侧近邻背景点分位数"，且只在 TSDF 无表面覆盖的条带生成假墙，避免与真实面交叉。

**G3 网格后处理（清碎补洞，接在 build_mesh 内）**
- 连通域过滤（删 < 阈值三角面数的漂浮碎片）、小孔填充（按边长阈值，保留门洞/楼梯口等大开口）、重复/交叉面裁剪、退化三角形清理、可选 1 次拉普拉斯平滑。
- `geometry_report.json` 增加：连通域数、边界环数、watertight 状态、主连通域占比；GLB 导出在此基础上。

## 三、执行顺序、验收与回退

执行顺序：**基线重测 → V1 → V2 →（V3 按收益）→ V4 → G1 → G2 → G3 → 测试+HANDOFF 2.9+提交推送**。每步完成后评估并保留旧产物快照（沿用 `background_video_xxx.mp4` + `masks_xxx_backup/` 命名惯例），失败即回退。

验收标准：
- 视频：沙发窗口 copy_mean≤0.15（现 ~0.5）；全片 copy_through≤0.08；闪烁比≤0.9；时序比≤0.90；`masks_inpaint` 全局覆盖率≤0.45 且仅漏检窗口升高（精准原则不破）。
- GLB：wall_source 不再依赖 footprint 假墙（或假墙与 TSDF 对齐无交叉）；结构壳除门口/楼梯开口外 watertight；主连通域≥95% 三角形；无 NaN/退化三角形；interactive.html 目视沙发后墙面连续无穿洞。

硬约束：不动 `outputs/001_sam31/`（回归基线）；不动三 conda 环境；ProPainter 仍走 vbr-seg；GLB 不作为视频指标；mask/prompt/代码变化后 `--force` 重跑；GPU7 优先（4/5/6 空闲可借用）。
