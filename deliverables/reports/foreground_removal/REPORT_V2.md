# 用位姿 + mask 去除前景（家具）—— v2 修正

日期：2026-09-24 · 工具：`tools/refuse_with_masks.py`（v2，替代 `tools/subtract_foreground.py`）

## 为什么有 v2

v1（`tools/subtract_foreground.py`）在**已融合的网格**上事后雕刻。用户反馈三个症状：
物体**只扣掉中间一块**、扣得**非常破碎**、还有**压根没扣掉**。

三个症状同一个根因：**雕刻是对"已经融进去的几何"做判断**。桌面和它脚下的地板在
TSDF 里是同一张连续曲面，任何事后规则都无法可靠区分。量化验证（射线投射，留出
关键帧，见下）确认 v1 只去掉了 **47%** 的家具，**53% 仍在**。

## 判据：不做事后判断，改成融合前就把家具排除

掩膜像素的深度在集成**之前**置零，Open3D 会跳过深度 0，那些像素不产生任何表面。
家具因此**在构造上就不存在**——没有残留边缘、没有碎片、没有幸存者。

保留基线**自己的**位姿/深度/置信度，只换掩膜，所以结果仍与基线 1:1 可比。

## 度量方法（这是本次的关键）

之前几版指标都被"分辨率/采样密度"污染（不同网格顶点数不同，像素覆盖数不可比）。
最终用**射线投射**，它直接回答"家具还在不在"：

对留出关键帧的每个家具像素投射一条射线，比较网格命中深度 vs 基线记录的深度
（基线融了家具，所以它的深度**就是**家具表面深度）：

- 命中深度 ≈ 家具深度 → **家具仍在**
- 命中深度明显更远 → 渲染到的是后面的墙 → **家具已去**（留下空洞，诚实结果）

## 数据

| 网格 | 家具仍在 | 渲染到墙（正确） | 无命中 |
| --- | --- | --- | --- |
| 基线（家具已融合） | **98.66%** | 1.22% | 0.12% |
| v1 雕刻 `subtract_foreground` | **53.02%** | 4.65% | 42.33% |
| **v2 掩膜重融合（本次交付）** | **11.41%** | 6.34% | 82.25% |

**家具残留 53.02% → 11.41%（4.6× 改善）**；基线 98.66% 证明该度量有效。

### 掩膜膨胀的消融

掩膜边缘本身不精确，紧贴边缘外侧的像素往往**也是**家具，于是长出一圈"领口"残留。
在置零前先膨胀掩膜即可消掉：

| 膨胀 | 家具仍在 |
| --- | --- |
| 0 px | 21.92% |
| 2 px | 16.78% |
| **4 px（采用）** | **12.15%** |
| 5 px（`masks/`） | 18.13% |

采用 `masks_inpaint`（流水线自己的精修膨胀集）+ 4px 膨胀。`--mask-dilate` 可调。

## 诚实的局限

1. **挖掉处留下空洞**（"无命中" 82%）。相机从未看到家具背面，那里本就没有几何。
   补面属于先验/扩散的工作（route A 用结构先验补），本工具**只负责移除**，不编造几何。
2. **残留 11.41% 不是 0**。剩余部分主要是掩膜系统性漏检的区域、以及家具与结构
   真正相连处（如柜体贴墙）。要再降需要更好的掩膜，而不是更好的雕刻规则。
3. 三角面 729122 → 683521（过滤后），比基线 444059 多——掩膜留洞后 TSDF 在洞缘
   生成更密几何。**这是移除的证据，不是缺陷**，但网格更大。
4. 阈值（膨胀 4px）在本条 71 帧走位上标定，换序列需重新标定；方法就是本文的射线投射。
